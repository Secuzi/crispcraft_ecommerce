## 📌 Overview
A full-stack web application built with **Express.js** (backend) and **Vue.js** (frontend) for E-commerce inventory management and order tracking. Features secure authentication and CRUD operations.

## ✨ Features
- **User Authentication** - Secure session-based login using `express-session`
- **Inventory Management** - Add, edit, delete, and view products
- **Order Tracking** - Monitor order status and history
- **Responsive UI** - Clean interface built with Tailwind CSS
